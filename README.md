# 🪨 On The Rock – Daily Report App

Kindergarten daily report card for children under 3 years old.

---

## 🚀 Deploy to Vercel in 5 Steps (FREE)

### Step 1 — Create a GitHub Account
Go to https://github.com and sign up for free (if you don't have one).

### Step 2 — Create a New Repository
1. Click the **+** button (top right) → **New repository**
2. Name it: `ontherock-report`
3. Set it to **Public**
4. Click **Create repository**

### Step 3 — Upload These Files
1. On your new repo page, click **uploading an existing file**
2. Drag and drop the ENTIRE `ontherock` folder contents:
   - `package.json`
   - `vercel.json`
   - `src/` folder (with `index.js` and `App.js`)
   - `public/` folder (with `index.html`, `manifest.json`, `icon.svg`)
3. Click **Commit changes**

### Step 4 — Deploy on Vercel
1. Go to https://vercel.com and sign up with your GitHub account
2. Click **Add New Project**
3. Find and select your `ontherock-report` repository
4. Click **Deploy** (no settings need to change)
5. Wait ~2 minutes ✅

### Step 5 — Your App is Live!
You'll get a URL like: `https://ontherock-report.vercel.app`

Share this URL with all teachers!

## 📱 Install on Phone (Add to Home Screen)

### iPhone (Safari only):
1. Open the app URL in **Safari**
2. Tap the **Share** button (box with arrow)
3. Tap **Add to Home Screen**
4. Tap **Add** — done! It appears as an app icon 🎉

### Android (Chrome):
1. Open the app URL in **Chrome**
2. Tap the **⋮ menu** (three dots, top right)
3. Tap **Add to Home Screen**
4. Tap **Add** — done! 🎉

## 👩‍🏫 How to Use

1. Open the app → tap **Set teacher name** (saves automatically)
2. Go to **Manage** → add all children in your class
3. Each day, tap **📝 Fill** next to each child's name
4. Fill in mood, meals, nap, diapers, activities, notes
5. Tap **Save & Preview** → send via WhatsApp 📲

---

## 💡 Tips

- Data is saved on each device (localStorage)
- Each teacher should set up the roster on their own phone
- History is saved per child — tap 📋 to view past reports
- Works offline once installed as a PWA
